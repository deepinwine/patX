# OA Excel 处理人更新设计

## 目标

导入新的 OA Excel 时，既能为新 OA 写入从未出现过的处理人，也能在不制造重复 OA、不静默覆盖人工数据的前提下更新已有 OA 的处理人。

## 当前问题

当前 OA 工作表会识别「处理人」列，但每个有效行都直接调用 `InsertOA()`：

- 新 OA 可以正确写入处理人；
- 重复导入同一 OA 会再次新增记录；
- Excel 中处理人发生变化时，不会更新原 OA；
- 用户无法看到处理人冲突数量，也无法选择覆盖策略。

## 方案比较

### 方案 A：精确匹配后受控更新（采用）

按「案件编号＋规范化 OA 类型＋发文日」匹配。唯一命中后只处理 `handler` 字段：原值为空时自动补入；原值与 Excel 不同时默认保留，并允许用户选择整批覆盖。

优点是避免重复记录，并保护已有人工字段。缺点是缺少 OA 类型或发文日的旧表无法自动匹配。

### 方案 B：按案件编号和最新 OA 更新

不要求 OA 类型和发文日，直接更新该案件最新一条 OA。实现简单，但可能把处理人写到错误的审查轮次，不采用。

### 方案 C：继续只新增

不会覆盖人工数据，但重复导入会持续制造重复 OA，也不能满足更新处理人的需求，不采用。

## 匹配与更新规则

### 匹配键

仅在以下三个字段都非空时尝试匹配：

```text
案件编号 geke_code
+ 规范化 OA 类型 normalized_oa_type
+ 发文日 issue_date
```

OA 类型复用现有 `NormalizeOaTypeCn()`，使「一通」和「第一次审查意见通知书」可以匹配到同一类型；非 OA 类型保留清理后的原值进行精确比较。

### 唯一匹配

同一匹配键恰好命中一条已有 OA 时：

| 已有处理人 | Excel 处理人 | 行为 |
|---|---|---|
| 空 | 非空 | 自动补入，计入“更新” |
| 与 Excel 相同 | 相同 | 不写数据库，计入“跳过” |
| 非空 | 空 | 保留已有值，计入“跳过” |
| 非空 | 不同且非空 | 计入“处理人冲突”，按本次导入策略处理 |

ExcelIO 先完成 OA 工作表预检，不写数据库。GUI 显示预计新增、自动补入、跳过、处理人冲突和匹配冲突数量，并提供三个选择：

- 「以 Excel 覆盖」：本次导入的全部处理人冲突均使用 Excel 值；
- 「保留原处理人」：本次导入的全部冲突均保留数据库值；
- 「取消导入」：不写入该 OA 工作表的任何数据。

### 未命中

没有匹配时新增 OA，并完整写入 Excel 中的处理人。处理人可以是数据库中从未出现过的新名字，导入后会出现在处理人筛选列表中。

### 不安全匹配

以下情况不自动更新：

- OA 类型或发文日为空；
- 同一匹配键命中多条已有 OA。

关键字段缺失时按新 OA 处理，保持现有导入兼容性；多条命中时跳过该行并计入“匹配冲突”，避免继续扩大重复数据。

## 组件边界

### `ExcelIO`

- 解析 OA 行；
- 生成不修改数据库的 OA 导入计划和分类计数；
- 执行新增、自动补入、保留或覆盖；
- 通过回调把一次整批预检结果交给 GUI，并接收覆盖、保留或取消策略；
- 在 `ImportResult` 中返回处理人冲突和匹配冲突数量。

### `Database`

新增只读精确查询接口，返回指定案件编号、规范化 OA 类型和发文日对应的 OA 列表。实际更新继续复用 `UpdateOA()`，确保撤销日志和其他字段保持一致。

### GUI

- 每个 OA 工作表只显示一次预检确认；
- 没有处理人冲突时仍显示新增、更新和跳过数量，用户可以确认或取消；
- 导入完成对话框展示新增、更新、跳过、处理人冲突和匹配冲突数量；
- 导入完成后继续调用 `LoadAllData()`，刷新 OA 页和处理人筛选项。

## 数据保护

- 匹配更新只修改 `handler`，不覆盖撰写人、摘要、期限、进度、备注、同步来源等字段；
- 空白 Excel 处理人永不清空已有处理人；
- 默认冲突策略为保留数据库值；
- 不唯一匹配永不选择“第一条”进行更新。

## 测试

自动测试至少覆盖：

1. 新 OA 写入全新的处理人；
2. 重复导入同一 OA 不新增重复记录；
3. 已有处理人为空时自动补入；
4. 相同处理人重复导入时跳过；
5. 不同处理人按“保留”策略不覆盖；
6. 不同处理人按“覆盖”策略更新；
7. Excel 处理人为空时不清空已有值；
8. 同一匹配键存在多条记录时跳过并报告匹配冲突；
9. OA 类型别名经过规范化后能够匹配；
10. 国内申请主档处理人及网页同步的人工字段保护规则不受影响。

## 不在本次范围

- 自动合并历史重复 OA；
- 同时更新撰写人、期限、进度或摘要；
- 根据申请号替代案件编号匹配；
- 区分初审补正和实审补正。
